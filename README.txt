# Birthday Webpage Recreation

This is a scene-by-scene interactive recreation inspired by the uploaded sample.mp4.

## Run
1. Keep the folder structure unchanged.
2. Open `index.html` in Chrome/Edge.
3. Add your own files:
   - `assets/photo1.jpg`
   - `assets/photo2.jpg`
   - `assets/photo3.jpg`
   - `assets/music.mp3`

## Change the secret code
Open `script.js` and change:
const secret='1432';

## Change the text
All visible birthday text is in `index.html`.

## Important
The video appears to be a screen recording of a webpage. The exact original images, music, fonts and source code are not contained in the recording, so this project recreates the visual/interactive sequence rather than claiming to be the original source.
